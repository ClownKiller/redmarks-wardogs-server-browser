Settings

Squad

Let your mates see which server you're heading to. Everything here is off until you turn it on, and nothing is shared unless you press Join.

This app only reads public server data from the Wardog Servers API (wardogservers.com). It never opens, reads or changes WARDOGS game files, and it doesn't run inside the game. Join starts WARDOGS the same way a Steam shortcut does.

Ping is an estimate: it measures your connection to a large data centre in each region, because server addresses aren't public.

Setting up squad presence

Discord announcements need no hosting. The app posts a line into one channel when you press Join. It can't read messages back, so there's no squad list in the app.

  1. In Discord, make a private channel for your crew, so only invited people see the posts.
  2. Open Server Settings, then Integrations, then Webhooks.
  3. Click New Webhook, pick that channel, then Copy Webhook URL.
  4. Paste it into Discord webhook link in Settings, and tick Discord announcements.
  5. Press Join on any server to test it.

If the link ever leaks, delete the webhook in Discord and make a new one. The old link stops working straight away.

This gives you a full Squad tab. You need web hosting that runs PHP. No database is needed.

  1. Find the webapi folder in the app's project files.
  2. Open config.php in Notepad and replace the example key with a long random one of your own. Save it.
  3. Upload the whole folder to your website, for example into a folder called squad.
  4. Open check.php in your browser (yoursite.com/squad/check.php). It tells you if anything is wrong, and shows the address to use.
  5. Paste that address into Address of squad.php here, paste the same key into Squad key, tick Web API, then click Create squad.
  6. Click Copy invite line and send it privately to each mate. They paste it in Settings and click Use invite in their app, type their name, and they're in.

Up to 30 people by default; change MAX_MEMBERS in config.php for more. Entries disappear after three hours on their own.
